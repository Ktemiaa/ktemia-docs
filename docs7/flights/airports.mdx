title: "Search airports"
---

Look up an airport or city code by name. Use the code as origin or destination on a flight search. Code in cURL, Python, Node, Go, Java, Ruby, and PHP.

Base URL: https://api.ktemia.com
Authentication: send header `X-API-Key` on every request.

`GET /flights/airports`

Find the airport and city codes a flight search accepts.

Origins and destinations on a flight search are airport or city codes, not names. This call turns a name or a code into the `code` you send as `origin` or `destination`.

Send `X-API-Key` the same way as on every other call. `query` is required. `country` and `locale` are optional and default to US and `en`.

## Which code to send

Use `airports[].code`. When `allAirports` is true, the code covers every airport in that city: `LON` is London, `NYC` is New York. A false value is one airport, such as `LHR` or `JFK`.

A query that matches nothing returns `200` with an empty `airports` list. A missing `query`, a blank `query`, a bad `locale`, or an unsupported `country` returns `400`. If the lookup itself fails, the response is `502 AIRPORTS_UNAVAILABLE`.

Airline codes for the `airlines` filter come from [Search airlines](/flights/airlines). Send `code` from that response. A name is rejected on the search.

## Response fields

- `query` (string, required): The query you sent, with surrounding spaces removed.
- `airports` (array of objects, required): Matching airports, best match first. Empty when nothing matches.
  - `code` (string, required): IATA airport or city code. Send this as `origin` or `destination` on [Search flights](/flights/search).
  - `name` (string, optional): Airport name. For a city code this is `All airports`.
  - `city` (string, optional): City the airport serves.
  - `region` (string, optional): State, province, or region. Null when the place has none.
  - `country` (string, optional): Country name.
  - `countryCode` (string, optional): ISO 3166-1 alpha-2 country code.
  - `timezone` (string, optional): IANA timezone, for example `America/Chicago`.
  - `allAirports` (boolean, optional): True when `code` is a city code that covers every airport in that city, such as `NYC` or `LON`.

## Example: London

`GET /flights/airports` → 200

Request:

```json
{
  "query": "london",
  "country": null,
  "locale": null
}
```

Response:

```json
{
  "query": "london",
  "airports": [
    {
      "code": "LON",
      "name": "All airports",
      "city": "London",
      "region": "England",
      "country": "United Kingdom",
      "countryCode": "GB",
      "timezone": "Europe/London",
      "allAirports": true
    },
    {
      "code": "LHR",
      "name": "Heathrow",
      "city": "London",
      "region": "England",
      "country": "United Kingdom",
      "countryCode": "GB",
      "timezone": "Europe/London",
      "allAirports": false
    },
    {
      "code": "LGW",
      "name": "Gatwick",
      "city": "London",
      "region": "England",
      "country": "United Kingdom",
      "countryCode": "GB",
      "timezone": "Europe/London",
      "allAirports": false
    }
  ]
}
```

_Trimmed: lists to 3 items, and query strings removed from URLs (shown as `?…`). Live responses return full booking URLs. The captured response is on [the canonical page](/flights/airports)._

## Skill

Claude Code, Cursor, and Codex can search with the Ktemia skills: `flight-search`, `car-search`, and `hotel-search`.
https://github.com/Ktemiaa/ktemia-skills

Install in Claude Code:

```
/plugin marketplace add Ktemiaa/ktemia-skills
/plugin install ktemia@ktemia
```

Set `KTEMIA_API_KEY` in the environment. The flight skill looks up airport codes, asks when a name matches several cities, and returns each seller’s booking URL. It does not book tickets. Do not guess origin, destination, or dates.
