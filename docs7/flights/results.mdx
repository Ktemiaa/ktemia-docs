Fetch a page of flight data for a search: 20 itineraries, a nextToken, an exact total. Code in cURL, Python, Node, Go, Java, Ruby, and PHP.

Base URL: https://api.ktemia.com
Authentication: send header `X-API-Key` on every request.

`GET /flights/results`

Read a page of a search identified by its token.

Pass the `searchToken` from `/flights/search` as the `token` query parameter to get page 1. Each response that has another page includes `nextToken`. This call usually answers in 1–2 seconds.

## What is in a page

`flights` is at most 20 itineraries. `availableFilters` describes this search; every `value` in it is a valid input on a new `/flights/search`. `providers` maps the seller codes on this page to display names.

The `id` on a flight is what `/flights/details` wants as `resultId`. Keep the token - details needs it too.

## Read more

Why one search lists several providers for the same flight: [flight aggregator API](https://www.ktemia.com/blog/flight-aggregator-api/). How far apart those prices can be: [we compared 1,703 flights across 57 booking sites](https://www.ktemia.com/blog/flight-price-spread/).

## Query parameters

- `token` (string, required): A `searchToken` from `/flights/search` for page 1, or a `nextToken` from the previous page. There is no page number to set.

## Response fields

- `flights` (array of objects, required): Up to 20 itineraries.
  - `id` (string, required): Opaque identifier of this itinerary. Pass it as `resultId` to `/flights/details`.
  - `legs` (array of objects, optional): One entry per takeoff-to-landing journey. A one-way has one, a round trip two, a multi-city one per `legs` item you sent.
    - `departure` (string, optional): Local departure time of the first segment.
    - `arrival` (string, optional): Local arrival time of the last segment.
    - `duration` (integer, optional): Total elapsed time in minutes, including layovers.
    - `stops` (integer, optional): Number of stops. `0` is nonstop.
    - `segments` (array of objects, optional): The individual flights that make up this leg.
      - `airline` (string, optional): IATA airline code, e.g. `B6`.
      - `flightNumber` (string, optional): Airline flight number without the carrier prefix repeated, e.g. `723`.
      - `origin` (string, optional): Departure airport for this segment.
      - `destination` (string, optional): Arrival airport for this segment.
      - `departure` (string, optional): Local departure time, ISO-8601 without a zone, e.g. `2026-12-03T13:59:00`.
      - `arrival` (string, optional): Local arrival time, same format.
      - `duration` (integer, optional): Block time in minutes.
      - `aircraft` (string, optional): Aircraft name when the carrier publishes one.
  - `bookingOptions` (array of objects, optional): Fares on this itinerary. Details expands each option with a booking URL, bags, and cabin amenities.
    - `providerCode` (string, optional): IATA code of the selling airline or agency.
    - `price` (number, optional): Displayed fare in the country’s native currency, per person unless noted.
    - `currency` (string, optional): ISO 4217 code of that country’s native currency.
    - `formattedPrice` (string, optional): Same fare, already formatted for display.
    - `totalPrice` (number, optional): Fare for the whole party.
    - `formattedTotalPrice` (string, optional): Whole-party fare, formatted.
    - `isDirect` (boolean, optional): True when this option is sold by the operating carrier.
    - `isFreeCancellation` (boolean, optional): True when the fare can be cancelled without a fee.
  - `totalProviders` (integer, optional): How many sellers offered this itinerary.
  - `isBest` (boolean, optional): True when this is the recommended option.
  - `isCheapest` (boolean, optional): True when this is the lowest fare on the page.
- `page` (integer, required): 1-based page number for the token you sent.
- `hasMore` (boolean, required): True when another page exists.
- `expiresIn` (integer, required): Seconds remaining on this search.
- `totalResults` (integer, optional): How many itineraries this search contains.
- `nextToken` (string, optional): Present when `hasMore` is true. Send it as `token` on the next `/flights/results` call.
- `availableFilters` (object, optional): Facets of this result set. Each `value` is a valid input on a new `/flights/search`.
  - `price` (object, optional): Observed price range of the search, in the country’s native currency.
    - `min` (number, optional): Lowest fare.
    - `max` (number, optional): Highest fare.
    - `average` (number, optional): Mean fare.
    - `currency` (string, optional): ISO 4217 code of the country’s native currency.
  - `stops` (array of objects, optional): `value` is `0`, `1`, or `2`. Send it back as `maxStops`.
    - `value` (string or integer, optional): The value to send back on a new search. For airlines this is the IATA code; for cabins it is `economy` / `premiumEconomy` / `business` / `first`; for alliances it is `oneworld` / `skyteam` / `starAlliance`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest fare in this bucket, or `null` if none.
    - `count` (integer, optional): How many itineraries fall in this bucket.
  - `cabins` (array of objects, optional): Feed `value` back as `cabin`.
    - `value` (string or integer, optional): The value to send back on a new search. For airlines this is the IATA code; for cabins it is `economy` / `premiumEconomy` / `business` / `first`; for alliances it is `oneworld` / `skyteam` / `starAlliance`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest fare in this bucket, or `null` if none.
    - `count` (integer, optional): How many itineraries fall in this bucket.
  - `airlines` (array of objects, optional): Feed `value` back as `airlines`.
    - `value` (string or integer, optional): The value to send back on a new search. For airlines this is the IATA code; for cabins it is `economy` / `premiumEconomy` / `business` / `first`; for alliances it is `oneworld` / `skyteam` / `starAlliance`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest fare in this bucket, or `null` if none.
    - `count` (integer, optional): How many itineraries fall in this bucket.
  - `alliances` (array of objects, optional): Feed `value` back as `alliances`.
    - `value` (string or integer, optional): The value to send back on a new search. For airlines this is the IATA code; for cabins it is `economy` / `premiumEconomy` / `business` / `first`; for alliances it is `oneworld` / `skyteam` / `starAlliance`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest fare in this bucket, or `null` if none.
    - `count` (integer, optional): How many itineraries fall in this bucket.
- `providers` (object, optional): Map of provider code to `{ name }` for the sellers on this page.

## Skill

Claude Code, Cursor, and Codex can search with the Ktemia skills: `flight-search`, `car-search`, and `hotel-search`.
https://github.com/Ktemiaa/ktemia-skills

Install in Claude Code:

```
/plugin marketplace add Ktemiaa/ktemia-skills
/plugin install ktemia@ktemia
```

Set `KTEMIA_API_KEY` in the environment. The flight skill looks up airport codes, asks when a name matches several cities, and returns each seller’s booking URL. It does not book tickets. Do not guess origin, destination, or dates.

Docs: https://www.ktemia.com/docs/api/flights/results/
