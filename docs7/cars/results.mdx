Car rental API and rentals API results in Python, JavaScript, Go, Ruby, Java, and PHP. Fetch a page of 20 cars, a nextToken, and an exact total. cURL included.

Base URL: https://api.ktemia.com
Authentication: send header `X-API-Key` on every request.

`GET /cars/results`

Read a page of a search identified by its token.

Pass the `searchToken` from `/cars/search` as the `token` query parameter to get page 1. Each response that has another page includes `nextToken`. This call usually answers in 1–4 seconds.

## What is in a page

`cars` is at most 20 vehicles. `bookingOptions` lists each seller and price. `availableFilters` describes this search; `carClass`, `transmission`, booking-site ids (as `providers`), and agency ids (as `agencies`) can be sent on a new `/cars/search`. `providers` and `agencies` map the codes on this page to display names.

The `id` on a car is what `/cars/details` wants as `resultId`. Keep the token - details needs it too.

## Read more

Why one car lists several booking sites: [car rental aggregator API](https://www.ktemia.com/blog/car-rental-aggregator-api/).

## Query parameters

- `token` (string, required): A `searchToken` from `/cars/search` for page 1, or a `nextToken` from the previous page. There is no page number to set.

## Response fields

- `cars` (array of objects, required): Up to 20 cars.
  - `id` (string, required): Opaque identifier of this car. Pass it as `resultId` to `/cars/details`.
  - `car` (object, optional): The vehicle.
    - `name` (string, optional): Vehicle name as listed, for example `Nissan Versa`.
    - `class` (string, optional): Display class, for example `Compact` or `Intermediate SUV`.
    - `classGroups` (array of strings, optional): Groups this car belongs to, such as `small` or `suv`. Matches `carClass` on a new search.
    - `image` (string, optional): Image URL.
    - `passengers` (integer, optional): Seat count.
    - `bags` (integer, optional): Bag count.
    - `doors` (integer, optional): Door count.
    - `transmission` (string, optional): `automatic` or `manual`.
    - `airConditioning` (boolean, optional): True when the car has air conditioning.
    - `fuelType` (string, optional): Fuel label, for example `Gas` or `Fully electric`.
    - `sipCode` (string, optional): ACRISS / SIP code when the supplier publishes one.
  - `agency` (object, optional): The rental company that owns the car.
    - `code` (string, optional): Agency code.
    - `name` (string, optional): Display name, for example `Europcar`.
  - `pickup` (object, optional): The pickup desk.
    - `locationId` (string, optional): Desk id. Different from the city id you sent as `pickupLocation`.
    - `type` (string, optional): Desk type, for example `IN_TERMINAL` or `NON_AIRPORT`.
    - `isAirport` (boolean, optional): True when the desk is at an airport.
    - `airportCode` (string, optional): IATA airport code when `isAirport` is true.
    - `address` (string, optional): Street address when the supplier publishes one.
    - `city` (string, optional): City of the desk.
    - `country` (string, optional): ISO 3166-1 alpha-2 country code.
    - `distance` (string, optional): Distance from the city centre, already formatted.
    - `lat` (number, optional): Latitude.
    - `lng` (number, optional): Longitude.
    - `rating` (object, optional): Desk reviews.
      - `overall` (number, optional): Desk score on a 0–10 scale.
      - `label` (string, optional): Short label for the score, for example `good`.
      - `count` (integer, optional): How many reviews the score is based on.
      - `breakdowns` (array of objects, optional): Per-category scores when the supplier publishes them.
    - `operatingHours` (array of objects, optional): Opening hours. `open` and `close` are `HHMM` integers, for example `730` is 07:30.
  - `price` (object, optional): Lowest total price on this car.
    - `amount` (number, optional): Numeric amount in the country’s native currency.
    - `currency` (string, optional): ISO 4217 code of that country’s native currency.
    - `formatted` (string, optional): Same amount, already formatted for display.
  - `bestOption` (object, optional): The cheapest seller for this car. Details expands every seller.
    - `provider` (string, optional): Seller code of the cheapest option.
    - `price` (object, optional): Total price.
      - `amount` (number, optional): Numeric amount in the country’s native currency.
      - `currency` (string, optional): ISO 4217 code of that country’s native currency.
      - `formatted` (string, optional): Same amount, already formatted for display.
    - `perDay` (object, optional): Average daily price.
      - `amount` (number, optional): Numeric amount in the country’s native currency.
      - `currency` (string, optional): ISO 4217 code of that country’s native currency.
      - `formatted` (string, optional): Same amount, already formatted for display.
    - `paymentType` (string, optional): `PREPAY` or `PAY_AT_PICKUP`.
    - `freeCancellation` (boolean, optional): True when this option can be cancelled without a fee.
    - `mileage` (string, optional): Mileage allowance, already formatted.
    - `fuelPolicy` (string, optional): Fuel policy name, for example `full-to-full`.
  - `bookingOptions` (array of objects, optional): Sellers for this car. Details fills in `providerUrl` on each one.
    - `provider` (string, optional): Seller code. `providers` on the page maps it to a display name.
    - `providerName` (string, optional): Display name of the seller.
    - `price` (object, optional): Total price for the hire.
      - `amount` (number, optional): Numeric amount in the country’s native currency.
      - `currency` (string, optional): ISO 4217 code of that country’s native currency.
      - `formatted` (string, optional): Same amount, already formatted for display.
    - `perDay` (object, optional): Average daily price.
      - `amount` (number, optional): Numeric amount in the country’s native currency.
      - `currency` (string, optional): ISO 4217 code of that country’s native currency.
      - `formatted` (string, optional): Same amount, already formatted for display.
    - `paymentType` (string, optional): `PREPAY` or `PAY_AT_PICKUP`.
    - `freeCancellation` (boolean, optional): True when this option can be cancelled without a fee.
  - `optionCount` (integer, optional): How many sellers offered this car.
  - `badges` (array of objects, optional): Highlights such as a discount label.
  - `discount` (object, optional): How this price compares with the class average, when published.
  - `viewRank` (integer, optional): Rank of this car in the search.
- `page` (integer, required): 1-based page number for the token you sent.
- `hasMore` (boolean, required): True when another page exists.
- `expiresIn` (integer, required): Seconds remaining on this search.
- `totalResults` (integer, optional): How many cars this search contains.
- `nextToken` (string, optional): Present when `hasMore` is true. Send it as `token` on the next `/cars/results` call.
- `availableFilters` (object, optional): Facets of this result set. `carClass`, `transmission`, `bookingSites` (as `providers`), and `agency` (as `agencies`) can be sent on a new `/cars/search`. The rest is for display.
  - `price` (object, optional): Observed price range of the search.
    - `min` (number, optional): Lowest total.
    - `max` (number, optional): Highest total.
    - `average` (object, optional): Mean total.
      - `amount` (number, optional): Numeric amount in the country’s native currency.
      - `currency` (string, optional): ISO 4217 code of that country’s native currency.
      - `formatted` (string, optional): Same amount, already formatted for display.
  - `carClass` (array of objects, optional): Vehicle classes. Send the matching public value as `carClass` on a new search (`small`, `medium`, `large`, `suv`, `van`, `pickup`, `luxury`, `convertible`).
    - `id` (string, optional): Value to send back. For `carClass` this is `SMALL`, `MEDIUM`, `LARGE`, `SUV`, `VAN`, `PICKUPTRUCK`, `LUXURY`, or `CONVERTIBLE`. For `transmission` it is `Automatic` or `Manual`. Public search accepts `carClass` as `small` / `suv` / … and `transmission` as `automatic` / `manual`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest total in this bucket, or `null` if none.
    - `count` (integer, optional): How many cars fall in this bucket.
  - `transmission` (array of objects, optional): Send `automatic` or `manual` as `transmission` on a new search.
    - `id` (string, optional): Value to send back. For `carClass` this is `SMALL`, `MEDIUM`, `LARGE`, `SUV`, `VAN`, `PICKUPTRUCK`, `LUXURY`, or `CONVERTIBLE`. For `transmission` it is `Automatic` or `Manual`. Public search accepts `carClass` as `small` / `suv` / … and `transmission` as `automatic` / `manual`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest total in this bucket, or `null` if none.
    - `count` (integer, optional): How many cars fall in this bucket.
  - `bookingSites` (array of objects, optional): Booking sites selling cars in this search. Send their `id` as `providers` on a new search.
    - `id` (string, optional): Value to send back. For `carClass` this is `SMALL`, `MEDIUM`, `LARGE`, `SUV`, `VAN`, `PICKUPTRUCK`, `LUXURY`, or `CONVERTIBLE`. For `transmission` it is `Automatic` or `Manual`. Public search accepts `carClass` as `small` / `suv` / … and `transmission` as `automatic` / `manual`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest total in this bucket, or `null` if none.
    - `count` (integer, optional): How many cars fall in this bucket.
  - `agency` (array of objects, optional): Rental companies in this search. Send their `id` (for example `avis`) as `agencies` on a new search.
    - `id` (string, optional): Value to send back. For `carClass` this is `SMALL`, `MEDIUM`, `LARGE`, `SUV`, `VAN`, `PICKUPTRUCK`, `LUXURY`, or `CONVERTIBLE`. For `transmission` it is `Automatic` or `Manual`. Public search accepts `carClass` as `small` / `suv` / … and `transmission` as `automatic` / `manual`.
    - `label` (string, optional): Display name.
    - `minPrice` (number, optional): Cheapest total in this bucket, or `null` if none.
    - `count` (integer, optional): How many cars fall in this bucket.
- `providers` (object, optional): Map of seller code to `{ name }` for the sellers on this page.
- `agencies` (object, optional): Map of agency code to `{ name }` for the rental companies on this page.
- `locations` (object, optional): Map of desk `locationId` to the pickup object used by cars on this page.
