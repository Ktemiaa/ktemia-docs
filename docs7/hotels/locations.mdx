Hotel API location lookup in Python, JavaScript, Go, Ruby, Java, and PHP. Turn a city, neighbourhood, or property name into the id a hotel search accepts. cURL included.

Base URL: https://api.ktemia.com
Authentication: send header `X-API-Key` on every request.

`GET /hotels/locations`

Find the location ids a hotel search accepts.

A hotel search takes a location id, not a name. This call turns a city, neighbourhood, landmark, airport, or property name into that id.

Send `X-API-Key` the same way as on every other call. `query` is required. `country` and `locale` default to US and `en`.

## Which id to send

Use `locations[].locationId` as `location` on [Search hotels](/hotels/search). `29230` is London. A neighbourhood and an airport in the same city have their own ids.

A row with `locationType: hotel` is a specific property. Its `locationId` is still the city, so a search for that id returns the city. Its `hotelId` is what [Hotel reviews](/hotels/reviews) takes, and it matches `id` on a result from that city.

A query that matches nothing returns `200` with an empty `locations` list. A missing `query`, a blank `query`, a bad `locale`, or an unsupported `country` returns `400`. If the lookup itself fails, the response is `502 LOCATIONS_UNAVAILABLE`.

## Response fields

- `query` (string, required): The query you sent, with surrounding spaces removed.
- `locations` (array of objects, required): Matching places, best match first. Empty when nothing matches.
  - `locationId` (string, required): Id to send as `location` on [Search hotels](/hotels/search). A city, airport, neighbourhood, and a named hotel in that city share this id.
  - `name` (string, optional): Full display name.
  - `city` (string, optional): City.
  - `region` (string, optional): Region or state when the place has one.
  - `country` (string, optional): Country name.
  - `countryCode` (string, optional): ISO 3166-1 alpha-2 country code.
  - `locationType` (string, optional): What this row is: `city`, `airport`, `neighborhood`, `landmark`, or `hotel`.
  - `lat` (number, optional): Latitude.
  - `lng` (number, optional): Longitude.
  - `hotelId` (string, optional): Present when `locationType` is `hotel`. This is the id [Hotel reviews](/hotels/reviews) takes. It is not a search location.
